# 3. Versión web: iPhone, iPad y cualquier navegador (gratis)

Es **la forma gratuita de tener Atril PDF en iPhone y iPad** sin pasar por el App Store. También funciona en Android, Chromebook, Windows, Mac y Linux desde el navegador.

**Dirección:** https://marcoshernandezparraga.github.io/atril-pdf/

---

## Paso 1. Activarla (una sola vez)

Está explicado en la guía 01, paso 3: **Settings → Pages → Source: GitHub Actions**.

Después se publica sola cada vez que sacas una versión. Para publicarla a mano en cualquier momento:

1. Pestaña **Actions** del repositorio.
2. En la izquierda, **Web (GitHub Pages)**.
3. Botón **Run workflow → Run workflow**.
4. A los 5–10 minutos, ✓ verde: ya está en la dirección de arriba.

## Paso 2. Instalarla en iPad o iPhone

1. Abre **Safari** (tiene que ser Safari) y entra en la dirección.
2. Pulsa el botón **Compartir** (el cuadrado con una flecha hacia arriba). En el iPad está arriba a la derecha; en el iPhone, abajo.
3. Baja y pulsa **Añadir a pantalla de inicio** → **Añadir**.
4. Aparece el **icono de Atril PDF** en la pantalla de inicio. Ábrela siempre desde ese icono: se ve a pantalla completa, como una app.

La propia app muestra estas instrucciones la primera vez que se abre en Safari.

## Paso 3. Instalarla en Android o en el ordenador (opcional)

- **Chrome / Edge:** al abrir la dirección aparece un botón **Instalar** (en la barra de direcciones o en el menú ⋮ → **Instalar Atril PDF**).

## Qué funciona y qué no

| | Versión web | App instalada (Android, Windows, Mac, Linux) |
| --- | --- | --- |
| Leer, pasar página, modos de vista, zoom | ✅ | ✅ |
| Pedal Bluetooth y teclado | ✅ | ✅ |
| Apple Pencil / lápiz, texto, pentagrama, imágenes | ✅ | ✅ |
| Carpetas-concierto, panel de páginas | ✅ | ✅ |
| Funciona **sin internet** (después de abrirla una vez) | ✅ | ✅ |
| «Abrir con… Atril PDF» desde otras apps | ❌ (se importan desde la app) | ✅ |
| Dónde se guardan las partituras | Dentro del navegador | Dentro de la app |

## Cosas importantes que conviene saber

- **Sin internet:** la primera vez hay que abrirla con conexión (descarga unos 18 MB). Después funciona sin conexión, también en un escenario sin cobertura.
- **PDF grandes:** funcionan; las páginas se preparan una a una para no llenar la memoria.
- **Tus partituras** se guardan dentro del navegador, solo en ese aparato. Si borras los «datos de sitios web» de Safari (Ajustes → Safari → Avanzado → Datos de sitios web) **se borran también**. Guarda tus PDF originales en la app Archivos o en tu ordenador.
- **Actualizaciones:** cuando publicas una versión nueva, la app se actualiza sola la siguiente vez que se abre con internet.
- **Privacidad:** igual que el resto de versiones: nada sale del aparato.
