# Seguridad / Security

**Español.** Atril PDF funciona sin conexión y sin servidores: tus partituras nunca salen de tu aparato. Si encuentras un problema de seguridad, por favor no lo publiques en un mensaje abierto: usa la opción privada **Security → Report a vulnerability** de este repositorio. La explicación completa de las protecciones está en [docs/SEGURIDAD.md](docs/SEGURIDAD.md).

**English.** Atril PDF works offline and has no servers: your scores never leave your device. If you find a security issue, please do not open a public issue: use the private **Security → Report a vulnerability** option of this repository. The protections are described (in Spanish) in [docs/SEGURIDAD.md](docs/SEGURIDAD.md).

Only the latest released version receives security fixes.
